# Lock-screen fonts

Bundled **Noto Sans** (Regular + Bold) for server-side lock-screen PNG text.

- Covers Latin + Cyrillic so sharp/resvg never falls back to `.notdef` tofu boxes.

- Source: Google Noto Sans (Noto fonts project).
